# PANINI-DR project page

Source of https://roychowdhuryresearch.github.io/PANINI-DR_Project_Page/, the project page for
"PANINI-DR: Controlled Deep Research through Generative Semantic Workspaces"
([arXiv:2610.15208](https://arxiv.org/abs/2610.15208)).

The page is a single static file (`index.html`) served by GitHub Pages from the `main` branch.
Figure 1 of the paper is reproduced as an interactive diagram; the results come from the paper's
Tables 1 and 2.

Code: https://github.com/roychowdhuryresearch/panini-dr
